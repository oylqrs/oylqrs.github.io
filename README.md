# 密码管理器介绍

- [keepass 数据库解析功能]
- [FIDO2 功能 支持10个FIDO2 私钥存储和公钥生成功能]
- [智能卡1 OpenPGP 功能 支持5张独立的OpenPGP 卡片]
- [智能卡2 PIV 功能 支持5张独立的PIV 卡片]
- [自定义脚本功能]
- [硬件钱包功能]
- [chameleon nfc 嗅探和模拟功能，支持可视化管理NFC卡片]
- [OTA升级功能，软件持续更新支持]
- [flash 硬件级加密]
- [硬件AES128/256 加密解密功能]
- [时间，温度，充电管理功能]
- [紧急清除数据功能]
- [U盘 16MB 存储KDBX数据库和重要数据]
- [完全离线不联网，保证私有数据不泄露]
