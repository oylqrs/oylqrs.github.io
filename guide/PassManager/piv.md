# PIV 的介绍和使用方法
- PIV 是什么
```
PIV 完整说明PIV = Personal Identity Verification（个人身份验证）
是美国 NIST 制定的 FIPS 201 标准智能卡应用规范（SP 800-73），广泛用于硬件密钥（YubiKey / CanoKey / 你的这款 PassManager 设备）。
核心本质PIV 是一套X.509 证书体系的智能卡应用，在硬件内部安全存储私钥 + 数字证书，私钥无法导出，所有签名 / 加密运算在芯片内部完成。
和你文档里另外两个模块区分：
PIV：基于 PKI/X.509 证书，面向 Windows 系统登录、智能卡登录、SSH 证书认证、mTLS；
```

- PIV 用途

```
1. Windows 智能卡登录

Windows 原生内置 PIV 驱动，插入硬件密钥即可代替密码登录电脑、锁屏解锁。

2.SSH 证书认证

服务器使用证书鉴权，相比传统 SSH 密钥更适合企业运维。

3.网站 / 服务 mTLS 双向证书认证

VPN、内网管理系统、API 双向加密校验。

4.文档 / 邮件数字签名

使用 X.509 证书对 PDF、邮件签名，防篡改、身份确权。

5.物理门禁拓展

支持对接符合 PIV 标准的门禁读卡器。
```
